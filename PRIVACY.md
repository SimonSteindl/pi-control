# Privacy policy for Pi Control

Pi Control is a self-hosted application. It connects directly to Raspberry Pi
servers selected by the user. The project developer does not operate a central
Pi Control cloud and does not receive account credentials, files, terminal
contents, photographs, scans, usage data, or analytics from the app.

## Data handled by the app

- Server addresses and login sessions are stored locally on the user's device.
- Files, photos, scans, notes, user accounts, logs, and backups are processed by
  the Raspberry Pi server chosen and administered by the user.
- Camera and photo-library access is used only when the user selects scanning,
  OCR, uploading, or media-backup features.
- Network and device information shown in the administration area comes from
  the user's own Raspberry Pi and local network.

## Third-party infrastructure

Users may connect their own optional services, such as ngrok for remote HTTPS
access or ntfy for notifications. Data sent through such services is governed
by the provider selected and configured by the user.

## Deletion and control

Administrators control all data stored on their Raspberry Pi. App sessions and
locally saved server connections can be removed from Pi Control. Uninstalling
the app removes its local application data; server-side data remains under the
administrator's control.
