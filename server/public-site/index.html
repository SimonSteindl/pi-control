RASPBERRY PI PROJECT

Pi-Control

A Raspberry Pi monitoring and management project, bringing system information and server controls together through a dedicated app and web interface.

Project features

  • System information, including CPU temperature and uptime
  • Memory and storage monitoring
  • Network information and status checks
  • CPU benchmarking and history
  • File management through the project interface
  • A mobile app connected to a Python/Flask server

Explore the project

Pi-Control is actively being developed. Visit the repository for the current source code, project documentation and available downloads.
