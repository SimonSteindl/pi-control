Quick answers

Before you get started.

Is Pi-Control a hosted cloud service?

No. Pi-Control is a self-hosted project intended to run on your own server. This public page is a static project website and is separate from your private instance.

Where can I download the app?

Check the GitHub Releases page for published builds and release notes. Availability can change as development progresses.

Does every feature work immediately?

Some features depend on server configuration, account permissions, connected storage, network access or a configured AI service. Follow the project documentation for current requirements.

How do I report a bug or request a feature?

Open the GitHub repository and use its issue tracker. Include relevant logs, steps to reproduce and your app/server version, but never post passwords, tokens or private data.
